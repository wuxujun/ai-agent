## Trace 基准

同一 SQLite 合成任务，每次追加一条，包含 checkpoint 的复制、比较和事务保存成本，`-benchtime=5x -count=1`，本机 darwin/amd64：

| 原有 Trace | 完整保存平均 | 增量保存平均 | 完整保存分配 | 增量保存分配 |
| --- | ---: | ---: | ---: | ---: |
| 1,000 | 5.50 ms | 1.00 ms | 1.57 MB | 0.66 MB |
| 10,000 | 66.87 ms | 6.69 ms | 15.63 MB | 5.65 MB |

这是 5 次短时本机合成样本，不是生产 P95、HTTP 吞吐或 PostgreSQL 证据。数据：`/private/tmp/ai-agent-trace-progress.log`；可复跑：

```sh
go test ./internal/store -run '^$' -bench '^BenchmarkTaskAppendProgress/' -benchtime=5x -count=1
```

增量进度使用不可变前缀副本和持久化维护版本。检查点过期返回 ErrTaskProgressConflict，整个事务回滚；内部步骤自行保存并推进任务版本时继续使用完整快照。没有新增数据库表或改变完整快照接口。

