## 外部 RAG/MCP 边界

共享 HTTP 模板改用现有 `policy.SafeHTTPClient`，通过校验过的 DNS 结果直接拨号，阻止私网/回环/link-local 与 DNS 二次解析窗口。未新增私网放行开关；现有私网 RAG 地址会被拒绝，需另行评审专用内网接入，不应关闭 policy 绕过。默认 search_url 仍为空。

每次查询独立创建 CookieJar；同次 SSE GET、initialize、initialized 与 tools/call 保留会话，下一次查询不会携带前次 Cookie。所有 HTTP 自动重定向禁用，避免 Authorization、Cookie 和 MCP session headers 被转发到其他地址。SSE endpoint 只允许相同 scheme 和 host:port，拒绝跨源、降级、不同端口、userinfo、fragment 或解析失败；拒绝时不退回继续发送携带凭据的请求。正常相对 endpoint 和 Streamable HTTP 保持现有握手协议、响应上限及取消/超时语义。

日志只记录 task/kind/method/origin/status/body_len，不记录查询、完整 URL、请求正文或上游响应预览。网络错误中的 URL 也仅保留 origin，同时保持 context 取消的 errors.Is 语义。

## write_file 目录竞争

保留 workspace/write policy；通过 `os.OpenRoot` 及 Root.MkdirAll/OpenFile 处理所有父目录和目标文件，防止校验后父路径被换成外部 symlink 时越界。打开前拒绝已存在的非 regular file；Unix 非阻塞打开并在 descriptor Stat 确认 regular 后才 Truncate 和 WriteString，避免 FIFO 阻塞或先截断特殊文件。末级 symlink 继续拒绝；创建缺失的内部父目录及覆盖普通文件的行为有回归。

工具入口拒绝已取消请求，并直接验证 path/content。此实现没有为文件内容增加新的大小限制，也不承诺原子替换或断电持久化；Windows 仅交叉编译，不宣称真实平台竞争验收。
