## 接口

```http
POST /api/retention/imports/verify?tenant_id=<configured-tenant>&byte_budget=1048576
X-API-Key: <administrator-credential>
Content-Type: application/json

<完整 task-joint-export-v2 JSON>
```

使用现有 AuthMiddleware、AdminMiddleware 与全局访问日志/恢复/追踪覆盖。必须明确已配置租户；普通凭据和伪造 X-Admin 无法使用。响应 Cache-Control: no-store，只返回验证结果与数量，不返回目标正文、审批密文、记忆、工作区路径或密钥。

成功响应示意：

```json
{"task_id":"task-id","tenant_id":"tenant-a","verified":true,"target":"ephemeral_isolated_sqlite","source_preserved":true,"restore_ready":false,"payload_sha256":"<原 payload SHA-256>","trace_count":2,"approval_count":1,"memory_count":1}
```

byte_budget 默认 1 MiB，4096–8388608，限制整个上传正文，不允许部分包或截断。Trace 最多 10000，审批和独立记忆各最多 1000。存储和验证使用请求取消与 15 秒期限；正文读取受 HTTP 服务器的读取超时约束。非法参数/包返回 400；未知租户 404；超限 413；取消/超时 504；沙箱故障或恢复内容不一致 503。所有错误为固定脱敏文本。

## 校验与恢复

仅接受 v2 联合包；v1 不能伪装完整恢复。严格检查 schema、原 payload 字节长度及 SHA-256、清单、数量、source_preserved=true、restore_ready=false、来源和导出时间。清单采用当前导出格式的确切字段及顺序。拒绝未知字段、重复 JSON 键、尾随 JSON、缺失必需清单字段及会被类型转换丢弃的字段/表示；审批参数使用 UseNumber，保留超出 float64 精确范围的整数。哈希证明内容一致性，不提供来源认证或数字签名；仅管理员可上传。

检查 Task/审批/独立记忆/session 的租户与 ID 关系，审批正版本、有效状态、关联请求及非空 action 密文，唯一依赖 ID；记忆 session 必须与 Task session 相同。检查 Trace 物理序号从 1 连续，Task 不含重复 Trace 数组，session 高水位不低于 Task.SequenceNo。原任务可为活动状态：恢复演练只验证观察到的联合数据，不说明源业务写入已全部完成。

TaskRestoreSandbox 专用构造器只创建私有 SQLite :memory: 数据库，不接受路径或在线连接，不实现正常 Store。Task、每条 Trace、每条审批、每条记忆及 session 分别存入 restore_parts，在一个事务内提交；重复任务 ID 拒绝，不覆盖。导入错误及取消会回滚。每次 API 请求新建并关闭自己的沙箱。

Verify 从这些独立记录重建联合快照，检查记录数量与顺序，并与原 payload 的规范 JSON 比较完整内容。保留原时间、Trace 序号、审批状态/版本/owner/密文、embedding、session 高水位及全部正文；不重新生成时间，不解密、不获取租约、不调用 SaveFullTask、不触发记忆索引或付费模型、不重新执行审批。原始 payload hash 随报告返回；规范比较容许对象键顺序/空白差异，不改数值精度。

## 验证范围与限制

本功能是请求专属、临时 SQLite 导入和恢复读回演练，不是持久归档或在线恢复入口。它不提供可恢复执行的任务，不重建外部审计、workspace 文件、密钥、其他 session 任务或执行租约。通过报告不改变导出包，也不签发 retention eligible 或删除许可；源 Store 不会传给恢复函数。

回归覆盖 Memory/SQLite 导出后的源快照不变；完整时间/密文/大整数/embedding/session 保真；错误 hash、字节、清单、计数、租户、关系、序号、状态与重复 ID 拒绝；JSON 歧义拒绝；并发导入仅一个成功；事务中途写入故障完全回滚；独立记录损坏导致验证失败；API 鉴权、参数、限额、正文脱敏及独立请求沙箱。
