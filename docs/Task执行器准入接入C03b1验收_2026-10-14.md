## 共用可选准入检查

新增 `internal/types/execution_admission.go` 的 `ExecutionAdmissionChecker` 与作用域上下文绑定。checker 只由可信构造代码设置，读取固定 Task ID/tenant，不能从任务、恢复包或配置字符串选择提供者。Engine/Coordinator 的 `ExecutionAdmission` 默认 nil，需在首次使用前固定，不能作为热重载字段。

- 同一 executor 的嵌套 RunAll/Next、Coordinator fallback 不重复叠加 checker；继承上层 checker，不因下层字段为 nil 而丢失。
- 固定 task/tenant scope。复用上下文到其他任务/租户拒绝；checker 收到独立 scope 副本，不能改动执行器的业务 Task。
- 不覆盖原有 `WithExecutionLeaseCheck`。原租约检查保持优先，随后做新增准入检查；取消仍传递，提供者错误脱敏为固定 admission denied，不输出上游正文。
- 没有绑定/checker 时保持原有行为，默认构造器/运行配置没有自动选择这套协议。

## 专用 SQLite attempt 检查器

新增 `internal/store/sqlite_execution_admission.go`：

`WithSQLiteExecutionAttempt(ctx, attempt)` 复制 C03a attempt 字段并绑定对应的 `WithTaskLease`，使业务保存沿用原有 lease guard；这不是认证凭证。

`SQLiteStore.CheckExecutionAdmission` 仅在 C03 专用 Store 可用。每次同事务只读核验核心内容历史与控制记录，要求：

- 上下文 attempt 与当前任务 ID/tenant、instance 摘要匹配。
- 当前 gate 为 open，gate epoch 与 attempt 准入版本一致，Task incarnation 匹配且未删除。
- durable attempt 仍为 running，lease owner 正确且检查时未过期。

无 attempt、错误 scope、closed gate、退出/完成、失效租约、损坏记录均拒绝。函数不登记、创建/续租/释放 attempt，不自动产生回执。上下文和本地数据库权限仍未认证，真实 writer fencing/独立控制面仍缺。

## 实际接入入口与边界

- `Engine.Next`、`Engine.RunAll` 在日志/Brain pinning/规划/执行等业务动作前绑定并检查准入；拒绝不改 Task 或调用 Planner。
- 现有 `executionLeaseError` 检查点同时复查新增 policy，包含 legacy 工具派发、RunAll 循环和审批/恢复的现有 lease 检查点。Planner 之后 gate 关闭会在审批/工具派发检查处拒绝。
- `beginApprovalRecovery` 在普通 recovery lease 获取前检查，覆盖 HTTP 和启动扫描共用的 Engine recovery 路径。未提供合法 attempt 时拒绝；**尚未将 recovery 的普通 owner/lease 生命周期换成 C03 attempt owner**，合法 attempt 下也不能因此宣称审批恢复已完整接入。
- `Coordinator.Run` 直接调用也检查显式或继承 policy；实际 workflow step 派发前复查 Engine 的继承 policy，不要求 HTTP handler 才能触发。
- 中途 admission denied 不作为执行器业务故障进行失败诊断，不把 Task 标记 failed 或触发附加诊断模型调用；已有取消语义保持。

未逐一接入每个 LLM/工具/宿主机回调的原子 fencing。准入只读检查后仍存在变化窗口，当前执行中的工具不会因单次 gate 关闭自动停止。Coordinator 的 detached persistence、API 外层最后 flush、审批恢复 owner、执行退出/renewal 停止与工具 cleanup 仍需 C03b2+ 接入，不能用这些检查点签完整 stopped 声明。

Engine 返回（包括完成、错误、拒绝或取消）后，C03a attempt 继续保留 running/exited 和 lease；不会从函数返回自动编造 exit/flush/cleanup。调用方必须在后续明确生命周期流程中收集回执，没有生成 eligible 或清理许可。
