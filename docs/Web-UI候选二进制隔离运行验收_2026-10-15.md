## 失败与边界

首次 HTTP 身份地址被候选配置校验拒绝；改为 HTTPS 后，macOS 系统证书池没有接受进程 SSL_CERT_FILE，认证请求在 TLS 阶段拒绝，不能记为登录通过。本轮 macOS 候选只完成启动/匿名与拒绝路径，完整认证链路在隔离 Linux 测试构建中完成；没有降低应用 HTTPS/TLS 策略或修改系统信任。

其后夹具调整包括：为容器 Secure Cookie 提供 HTTPS 入口、正确配置客户端证书信任、等待端口启动期间的连接关闭，以及将测试租户 workspace 放回应用工作目录内。原 workspace 越界被 policy 正确拒绝。先前失败日志与临时目录保留，不当作生产漏洞复现或通过结果；最后一轮完整运行退出 0。

此前 macOS 归档与 manifest 中 NOT_RUN 是打包时快照，未回写或重打包；后续执行证据以本文为准。仍不能据本轮声称现有 8088 后端已包含修复或真实外部身份系统登录已成功。
