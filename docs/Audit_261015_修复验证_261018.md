## 回归覆盖

- 总线启用后孤立审批任务仍可取消，审批失效。
- 普通审批恢复随 Shutdown 取消，关闭后不再接纳新恢复。
- Store.Close 等待后台索引，关闭后拒绝新索引。
- SQLite/Memory 单任务及全部任务删除清理审批、会话记忆，同时保留独立记忆。
- SQLite 新连接及重开连接均启用外键；后台记忆写入不能复活已删除任务。
- Redis 实际服务验证新旧记忆索引、审批索引清理和跨租户拒绝的无副作用。
- SQLite 审计过滤、分页、阶段条件必须匹配同一阶段，查询不解码完整 Task；Unicode 空白答案不计入 eligible。
- 超大 Prompt 响应有界读取并关闭；重定向不携带 BasicAuth 到目标。
- JWKS 拒绝私网拨号及明文 URL。
- 超过 1000 条失败任务的启动扫描完整性。
- Watch/手动重载更新 logger，日志重配失败保留上一快照。
- Postgres 增加 opt-in 集成测试 `TestExternalPostgresAuditProjectionAndDeletion`；本机未配置 Postgres，未声明已通过真实服务验证。
