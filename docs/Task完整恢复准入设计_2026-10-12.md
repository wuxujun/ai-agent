## restore_ready=true 的必要证据

未来必须使用独立准入评估结果，而不是修改现有验证器的固定标志。任意必要项缺失、过期或无法验证都拒绝准入；缺失清单可列出类型与脱敏标识，不记录正文、凭据或审批密文。

| 范围 | 准入证据与失败策略 |
|---|---|
| workspace 文件 | 清单包含任务所需路径、大小、hash、来源与权限；恢复到全新租户根目录，验证路径穿越/符号链接限制和字节预算。缺失文件阻止执行；不从任意服务器路径或在线 workspace 补齐 |
| 密钥管理 | 通过秘密管理提供正确历史解密版本，验证审批密文可读；不把密钥加入导出包或报告。缺失版本阻止准入；不能用新密钥覆盖原记录 |
| 外部审计 | 提供完整审计引用、审批决策依据与可验证的连续性证据；明确各记录归属和访问权限。缺失必需审计阻止准入；不伪造审计历史 |
| session 与其他任务 | v2 只有一个任务与 session 高水位，不能据此覆盖完整会话。验证关联任务/依赖图/租户与高水位一致性、ID 冲突和并发写入版本；缺失依赖阻止执行，不合并未知在线状态 |
| 执行状态与租约 | 明确终态任务是否允许重跑；非终态必须核对检查点、执行器版本与工具副作用。旧租约不导入，使用新的隔离执行身份；证明旧执行器不会同时执行。无法证明则阻止准入 |
| 审批与外部副作用 | 历史审批不直接授权新执行；验证审批有效期、owner、风险策略和租户权限。网络写入、付款、发布等副作用需幂等键和外部对账证据；无法确认已执行状态时阻止重放 |
| 记忆与索引 | 原 embedding 保真不等于当前检索可用；核对模型/维度/索引版本、会话权限。明确是否需要在独立目标重建索引，禁止顺带修改源索引 |
| 目标隔离与兼容性 | 校验目标身份、租户映射、schema 与运行时版本、工具可用性、策略和预算；先在不连接业务库、不执行副作用的隔离环境演练。导入冲突不得覆盖目标已有记录 |
| 故障与准入时效 | 证据绑定导出 hash、目标身份、版本与评估时间；导入、验证或状态变化使旧证据失效。演练有期限，失败保留现场；证据全通过后仍须完成明确的在线恢复实现与评审 |

## 后续实施边界

先定义可版本化的依赖清单和准入报告，再实现只读评估器；用缺失项、跨租户、过期证据、ID 冲突与状态变化回归证明 fail-closed。随后在全新专用目标中验证完整依赖导入和执行准备，保持源数据不变。只有独立在线恢复流程实现并评审后，才能设计受控切换。

恢复准入与源记录移除是两个流程。即使未来准入通过，也不自动赋予 retention eligible、归档执行或删除源记录权限；删除另需可审查的恢复证据、保留期、外部依赖与审批。
