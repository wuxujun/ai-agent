# 外部存储隔离验收与兼容性修复

本轮续作补齐 O10 的本机 PostgreSQL/Redis 验收，并修复验收发现的兼容性问题。实现基于 `17def1b`，本轮修复与验收已纳入本地提交，准确提交号以 Git 记录为准；尚未推送或部署。当前入口见 [优化状态](当前优化状态_2026-10-18.md)。

## 环境与隔离

- 使用本机缓存镜像 `pgvector/pgvector:0.8.2-pg17-bookworm`、`redis:7.4.2-alpine`，未下载新镜像。
- 两个专用容器名为 `ai-agent-o10-pg-20261018`、`ai-agent-o10-redis-20261018`，仅绑定 `127.0.0.1` 的随机端口。
- PostgreSQL 数据放在临时 tmpfs，Redis 禁用快照和 AOF；测试使用专用数据库，不复用已有业务容器或数据库。验收结束后已停止两个临时容器。
- 未连接真实身份供应商、调用付费模型、切换生产配置或操作既有 8088 服务。HA、DAG 放量及恢复控制面开发没有启动。

## 验收发现及修复

### PostgreSQL 后台记忆写入类型冲突

审计/删除集成用例在 `SaveMemory` 报 `42P08`：生成的 `INSERT ... SELECT ... WHERE EXISTS` 对同一 `$4` 同时从记忆字段和父任务 ID 推导不同类型。仅给 WHERE 中的参数加 cast 不足以消除歧义。

修复在 SELECT 投影及父任务条件两处显式使用 `$4::text`，普通检索和 pgvector 分支保持一致。原有父任务 `FOR KEY SHARE` 检查保留，删除任务后后台索引不能重新生成孤立记忆。

新增真实 PostgreSQL 回归覆盖普通/pgvector 两种分支、父任务存在时成功写入、父任务删除后拒绝复活。既有审计投影/删除回归也通过。

### PostgreSQL 导出预检不支持 jsonb

Task 和联合导出的大小预检直接对 `answer_audit_json`、`request_json` 等字段调用 `octet_length`，PostgreSQL 对 jsonb 没有该重载，报 `42883`。

修复将 JSON 字段转为 TEXT 后计量，并让 Task/Trace 预检复用依赖导出的统一函数。bytea 审批密文保持原始字节计量，不转成十六进制文本。事务隔离、最终编码字节预算和源数据只读约束保持原契约。

新增真实 SQL 回归同时使用中文 JSON 和二进制数据，验证类型兼容与字节数；稳定导出、联合导出、预算限制及隔离恢复读回通过。

### Redis 外部测试夹具隔离

- 保留评估用例原先假设全局迁移标记不存在；同一专用库已被其他契约初始化后，重复运行会在“未迁移”断言失败。夹具现在临时移动唯一迁移标记并恢复，不清空数据库。
- 全库逐键快照容易受其他用例遗留的短期租约自然过期影响。联合导出/恢复的只读断言改为 EVAL_RO 原子快照：保留全部持久化键与当前 fixture 的所有键，排除其他 fixture 的过期租约。新增回归确认无关 TTL 过期不造成误判，同时当前 fixture 的变更仍会被检测。
- Redis 生产导出代码没有修改；继续使用服务器强制只读的 EVAL_RO/EVALSHA_RO，不通过放宽写入限制来使测试通过。

## 外部契约结果

```sh
GOARCH=arm64 \
AI_AGENT_RUN_EXTERNAL_INTEGRATION=true \
AI_AGENT_RESTORE_DEDICATED_DB=true \
TEST_POSTGRES_DSN='postgres://ai_agent@127.0.0.1:<pg-port>/ai_agent_test?sslmode=disable' \
TEST_REDIS_URL='redis://127.0.0.1:<redis-port>/0' \
go test -race -v -p=1 -count=2 -timeout=180s ./internal/store ./internal/api \
  -run '^TestExternal(Stores|Redis|Postgres|SessionCreationConflictAndBackendFailure)'
```

退出码 0；35 个不同的顶层外部契约各通过两轮，共 70 条顶层 PASS 事件，不把子测试或跳过项重复计入。日志：`/private/tmp/ai-agent-o10-storage-contracts-final-v2.log`。

覆盖本轮会话重复/跨租户保真/后端失败分类，PostgreSQL 增量 Trace 旧前缀不重复提交、维护版本冲突、同版本并发一胜一拒、租约拒绝、重排/截断/回滚，以及既有任务创建、跨客户端暂停、审批 CAS/恢复、分页/索引、生命周期、轻量流快照、导出与隔离 SQLite 读回。

`TestExternalPostgresParadeDBHybridRanking` 两轮均因当前镜像缺少 pg_search 扩展而跳过，不计为通过。pgvector 排序已通过。隔离恢复的 `restore_ready=false` 保持不变；读回成功不授予在线恢复或清理许可。
