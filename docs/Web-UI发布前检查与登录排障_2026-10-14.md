## Bearer Token 与会话密钥

当前主配置使用 `api.auth.mode: introspection`。用户输入组织身份服务签发的访问 Token，后端携带 `Authorization: Bearer <Token>` 请求配置的 HTTPS 校验接口，按可信响应提取 active 与 tenant 等字段。本项目没有对应外部身份系统的登录/Token 签发接口，不能用随机字符串或自行签名 JWT 代替现有身份服务承认的 Token。准确配置以运行时环境和 `config.yaml` 为准。

`AI_AGENT_CONSOLE_SESSION_KEY` 是服务端会话 Cookie 的 AES-GCM 加密/校验密钥，不是登录 Token，不替代 Bearer 认证。要求标准 Base64 解码后为 32 字节；可用 `openssl rand -base64 32` 生成一次并保存至秘密管理或受保护的环境配置。多个实例须一致、更换后旧会话失效，不要每次启动重新生成，也不要提交 Git 或发送到聊天。

## 本机登录报错排障
