## 已改变的行为

统一 `RunCommand` 不再隐式继承服务进程的全部环境。`execute_code`、`run_tests`、Git diff、rg/grep 和 find 的命令执行路径均经过该入口；命令白名单、高风险审批、工作区参数检查、超时、进程组取消和输出上限保留。

默认仅继承服务环境中存在的以下变量：

```text
PATH LANG LC_ALL LC_CTYPE LC_MESSAGES TZ TMPDIR TMP TEMP
SYSTEMROOT WINDIR COMSPEC PATHEXT
```

Windows 上按大小写不敏感匹配环境名，其他平台按精确名称匹配。子进程 `HOME`、`USERPROFILE`、`PWD` 设置为命令工作目录的绝对路径；`GIT_CONFIG_NOSYSTEM=1`，`GIT_CONFIG_GLOBAL` 指向平台空设备，避免读取服务账户的 Git 全局配置。不会覆盖已有文件、创建凭证文件或修改服务自身环境。

因此上游 API key、审批加密/Console 密钥、云凭证和 SSH agent 不再默认传入任务。`BASH_ENV`、`ENV`、`NODE_OPTIONS` 等启动注入变量同样不默认传入。直接使用 `exec.Command` 的测试夹具和 MCP 服务接入不属于这个任务命令入口，没有因此改写它们的环境。

## 配置与兼容性

新增 `tool.environment_allowlist`，是默认系统变量之外、经运维审核后允许继承的**变量名**列表，不接受值，不接受通配符，不能由工具请求或模型参数修改：

```yaml
tool:
  timeout_seconds: 120
  environment_allowlist: [GOCACHE, GOMODCACHE, GOROOT, GOTOOLCHAIN]
```

也可通过 `AI_AGENT_TOOL_ENVIRONMENT_ALLOWLIST=GOCACHE,GOMODCACHE` 配置；这是服务配置输入，其自身不会传入工具。默认列表为空，严格生产示例也为空。

非法名称、大小写不敏感的重复、服务凭据家族、常见 KEY/TOKEN/SECRET/PASSWORD/AUTH/DSN 字段、SSH agent、数据库密码、含潜在认证信息的代理变量、动态加载器/解释器注入设置、Git 配置注入及受管理的 HOME 等不能加入名单。错误只报告固定原因，不回显环境值。对于自定义名称，管理员仍须审核变量实际内容；名称校验不能识别任意别名中的秘密。

这是默认行为收紧：依赖服务 HOME、Git 全局身份/credential helper、Go 缓存、语言运行时或代理环境的旧命令可能需要调整。Go 缓存/工具链变量可按需显式审核并加入名单；应用服务密钥和启动注入设置不能用名单恢复。需要远端认证的任务应另行使用隔离执行身份和专用凭据，不能共享服务凭据。

列表支持热重载，下一条命令读取最新快照；已经启动的进程保持启动时环境。有效重载生效，非法候选保留旧配置及 revision；配置快照对列表深复制，重载 diff 只记录字段 changed，不输出变量值。运行入口还会校验列表，避免直接构造非法配置绕过正常加载校验。

## 安全边界

本批只限制**环境继承**，没有完成 OS 沙箱。任务进程仍以服务账户权限执行，通用解释器仍可能读取主机文件、`.env`、项目配置或缓存，通过网络获取数据，或者创建子进程。PATH 中的可执行文件及已授权工作区内的配置也没有经过容器隔离。不能据此宣称凭据在所有访问方式下不可读。

F04 仍需独立执行账户/容器、挂载和网络限制、CPU/内存/进程数限制，以及越界读取、外网连接、子进程扩散和资源超限的真实验证。现有文件工具 `os.Root` 防护和高风险审批继续保留；如果接收不可信代码，完整执行隔离仍是上线前置项。

```bash
go test ./internal/policy/commandenv ./internal/tools ./internal/config -run 'Test(Build|Allowlist|RunCommand|ToolEnvironment|RestartGuard)' -count=1
go test -race ./internal/tools ./internal/config ./internal/policy/commandenv
go test ./...
go vet ./...
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -o /private/tmp/ai-agent-commandenv-server.exe ./cmd/server
```

本批最终结果：全仓 50 个含测试包、6 个无测试包通过；tools/config/commandenv 三包竞态通过；`go vet ./...`、Windows/amd64 server 编译、差异及文档链接检查通过。

首次全仓/竞态只因主配置新增显式空列表造成中英文配置键不一致而失败；已将主配置入口保留为可选注释，代码默认仍为空列表，中文配置未改动，复验通过。Windows 构建曾提示模块 stat cache 写权限，但最终退出码为 0；该结果只证明可编译，不代表在 Windows 上实际运行。
