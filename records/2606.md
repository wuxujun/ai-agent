## 项目架构

  项目是一个 Go 语言多模式 AI Agent 框架，核心组成：

  • 5 种执行引擎： eino / adk / legacy / step / multiagent 
  • 3 角色多智能体： PlannerAgent → ResearcherAgent → WriterAgent 
  • RAG 记忆系统：本地向量搜索 + 第三方 RAG URL
  • 多后端存储：SQLite / PostgreSQL / Redis / In-Memory
  • 全链路可观测：OpenTelemetry Trace + Metric

  ## 核心可扩展/优化方向

  ### 🚀 高优先级 (P0-P1)

   方向                                                          | 现状问题                                                      | 建议
  ---------------------------------------------------------------|---------------------------------------------------------------|---------------------------------------------------------------
   Research Phase 并发化                                         | Steps 严格串行执行，耗时叠加                                  | 无依赖步骤并行执行，预计提速 40-60%
   API 分页/过滤                                                 |  listTasks  未暴露  Store  的分页能力                         | 支持  ?status=&limit=&offset=  参数
   SSE/WebSocket 推送                                            | 客户端只能轮询  GET /api/tasks/:id                            | 新增  /stream  端点实时推送 StepTrace
   LLM Provider 插件化                                           |  llm.go  硬编码  switch ，新增 Provider 需改核心代码          | 定义  LLMProvider  接口 + 注册表模式
   结构化日志                                                    | 全用  log.Printf ，生产难过滤                                 | 引入  slog  /  zap ，支持日志级别
