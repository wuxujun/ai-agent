新增场景
  - multiagent_replanner
  - task_finalizer
  - context_compressor
  - answer_verifier
  - memory_summarizer
  - rag_query_rewriter
  - rag_reranker

  行为

  - Replanner 可使用独立的强推理模型。
  - Legacy/Eino 可通过 task_finalizer 二次生成最终答案。
  - Trace 达到 context_compression_trace_threshold 后可进行上下文压缩。
  - MultiAgent Writer 输出可通过独立 Verifier 校验；不支持的答案会降为 low confidence。
  - 长期记忆可使用 LLM 提炼可复用事实。
  - RAG 查询可重写，候选记忆可重新排序。
  - 所有新增能力仅在对应 Scene 显式配置后启用。
  - LLM 调用失败均回退到现有确定性路径，不阻断任务。
  - Scene 新增、删除和模型修改支持热加载。
  - Embedding 查询与文档仍共享同一 Profile，避免向量空间不一致。
  - 审批、路径检查、SSRF 防护和预算判断未引入 LLM已按推荐顺序完成全部场景扩展。

  新增场景

  - multiagent_replanner：失败重规划可使用更强模型。
  - task_finalizer：Legacy/Eino 可独立生成最终答案。
  - context_compressor：Trace 达到配置阈值后自动压缩。
  - answer_verifier：对 MultiAgent Writer 答案做证据校验。
  - memory_summarizer：生成更适合长期检索的事实摘要。
  - rag_query_rewriter：检索前重写查询。
  - rag_reranker：对候选记忆语义重排。

  行为约束

  - 新场景只有在 llm.scenes 显式配置后才启用。
  - 调用失败均回退至原有确定性路径，不阻断任务。
  - 配置增加或删除后可热加载生效。
  - Context Compressor 默认 Trace 阈值为 8。
  - Answer Verifier 不修改答案，只在证据不足时降低置信度并记录问题。
  - Embedding Profile 未拆分，避免查询与文档向量空间不兼容。
  - 审批、路径校验、SSRF 防护等安全策略没有引入 LLM。

  示例已经写入 config.yaml：

  llm:
    context_compression_trace_threshold: 8

    scenes:
      multiagent_replanner:
        model: "agent-planner-strong"

      task_finalizer:
        model: "agent-writer"

      context_compressor:
        model: "agent-fast"

      answer_verifier:
        model: "agent-verifier"

      memory_summarizer:
        model: "agent-fast"

      rag_query_rewriter:
        model: "agent-fast"

      rag_reranker:
        model: "agent-reranker"
